# Vendored libvterm

This directory contains an unmodified copy of [libvterm]'s library sources
(`include/` and `src/`), vendored so ptx can build against a known, recent
version instead of whatever the host happens to package.

## Why a separate folder

ptx itself is 0BSD. MIT and 0BSD are compatible, but keeping the upstream
sources in their own directory with their own `LICENSE` keeps the two clearly
separated: `CMakeLists.txt` builds this folder as its own target
(`vterm`, a **shared** library), and the ptx executable only links against
it. Do not fold these files into `src/`.

## Local modifications

None. `src/encoding/*.inc` are the pre-generated tables from upstream (they
are generated by `tbl2inc_c.pl` from the `.tbl` sources, which are not
vendored).

When updating, replace `include/`, `src/` and `LICENSE` wholesale from a new
upstream checkout and update the commit hash above.
